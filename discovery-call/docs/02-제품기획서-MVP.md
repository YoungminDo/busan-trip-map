# 「나를 발견하는 통화」 제품 기획서 (PRD) — MVP v1
기준: 전략 기획안 v2.5 / 플랫폼: iOS 단독 / 개발 기간: 10주 (WoZ 통과 후)

> 한 줄 정의: 대학생 사용자가 정한 시간에 AI 페르소나가 진짜 전화(CallKit)를 걸어 3–5분간 하루를 물어보고, 통화 종료 30초 안에 "내 말투의 일기 + 내 발화를 인용한 관찰 한 문장"이 도착하는 앱.

---

## 1. 스코프

**v1에 있는 것**: 온보딩(페르소나 선택→첫 통화), 데일리 통화(CallKit 수신, 거절 3옵션, 부재중 폴백), 통화 후 요약 카드(일기·감정태그·L1 미러링·전사·오디오·삭제), 주간 요약, 기억 콜백(7일 요약 주입), 설정(시간·페르소나·시험기간 모드·데이터 관리), 무료 주 5회·5분 캡, 월 구독 1종(Week 10+), 위기 프로토콜, 원가 대시보드(내부).

**v1에 없는 것 (만들지 않는다)**: '나' 탭(L3 프로필), Wrapped, 감정 히트맵, 적응형 스케줄링, Android, 학기권·단건 리포트, Memory 편집 탭, E2E 암호화, 프리미엄 TTS, 전면 비동기 모드.

## 2. 정보 구조 (IA)

```
앱 구조 (탭 없음 — 단일 스택, v1은 최소 화면)
├─ 홈: 일기 카드 리스트 (시간 역순) + 다음 통화 예고 배너
│   └─ 일기 상세 (= 통화 후 요약 카드와 동일 뷰)
├─ 주간 요약 (매주 월요일 아침 발행, 홈 상단 카드로 진입)
├─ 설정
│   ├─ 통화 시간 (요일별) / 시험기간 모드 / 일시정지
│   ├─ 페르소나 변경 (보라/무주/해나)
│   ├─ 데이터: 개별 삭제 안내, 전체 내보내기, 원본 보관 기간, 계정 삭제
│   └─ 구독 관리 (Week 10+)
└─ 시스템 표면 (앱 밖)
    ├─ CallKit 수신 화면 (잠금화면 풀스크린)
    ├─ 부재중 알림 + 답장 입력 (Notification action)
    └─ 일기 도착 알림 (통화 종료 +30초)
```

원칙: **v1의 화면 디자인 투자는 '통화 후 요약 카드' 단 하나에 집중한다.** 나머지는 시스템 기본 컴포넌트 수준으로.

## 3. 핵심 유저 플로우

### F1. 온보딩 (목표: 가입 → 첫 일기까지 5분)

```
앱 실행 → 로그인(Apple/카카오) → 생년 확인(19세+ 게이트)
→ [페르소나 선택] 카드 3장(보라/무주/해나), 탭하면 5초 인사말 재생, 1개 선택
→ [통화 시간 선택] 기본값 22:30, 15분 단위 휠 + "지금 바로 첫 통화 받아보기" 버튼(기본 강조)
→ [마이크 권한 프라이머] "통화하려면 마이크가 필요해요" → OS 권한 팝업
→ [알림 권한 프라이머] "전화가 울리려면 알림 허용이 필요해요" → OS 권한 팝업
→ 3초 후 CallKit 수신 화면 (선택한 페르소나 이름으로)
→ 첫 통화 (3분 축약판: 녹음 고지 → 요즘의 고점/저점 각 1개)
→ 통화 종료 → 30초 내 푸시 "첫 일기가 도착했어요" → 요약 카드
```

- 첫 통화 시작 직후 음성+화면 동시 고지(필수): "이 통화는 녹음되고 글로 바뀌어서, ○○님만 볼 수 있게 저장돼요."
- 실패 분기: 마이크/알림 거부 시 → 거부 상태 설명 화면 + 설정 딥링크. 첫 통화를 건너뛰면 홈에 "첫 통화 받기" 카드 고정.

### F2. 데일리 통화 (코어 루프)

```
[서버 스케줄러] 유저 설정 시각 → VoIP push → CallKit 풀스크린 수신
→ (받음) 통화 3–5분 → 연착륙 랩업 → 종료 → 비동기 파이프라인 → +30초 일기 푸시
→ (거절) 액션 3개: [10분 뒤] [오늘 밤 22:30] [오늘은 패스] — 어느 것도 페널티 없음
→ (무응답) 5분 후 재시도 1회 → 다시 무응답 → 부재중 알림
   "괜찮아요, 내일 다시 걸게요. 오늘은 문자로 남겨도 돼요" + 답장 입력(텍스트/30초 음성메모)
   → 답장 오면 동일 파이프라인으로 일기 생성
```

- 재시도 정책: 당일 최대 2회 호출(원 호출 + 5분 후 1회). 전략서의 "최대 3회"는 스누즈 선택 포함 기준.
- 주 5회 무료 소진 시: 전화를 걸지 않고, 다음 통화 가능일을 홈 배너에 표시. "소진" 표현 금지 — "이번 주 통화를 다 했어요. 다음 통화는 월요일이에요."

### F3. 주간 요약

매주 월요일 08:30 푸시 → 카드 1장: 자주 나온 주제 3개 + 감정 흐름 한 줄 + 날짜 박힌 인용 1–2개 + (말미) 되돌려주기 한 줄("지난주에 세 번 ○○하고 싶다고 했어요"). 대화 5회 미만이면 발행하지 않는다.

## 4. 화면 명세

### S1. CallKit 수신 화면 (시스템)
- 발신자명: 페르소나 이름 (예: "보라"). 앱 아이콘 뱃지.
- 수락 → 통화 화면. 거절 → 시스템 거절로 처리하되, 직후 로컬 알림으로 3옵션 제공(10분 뒤/오늘 밤/패스).

### S2. 통화 중 화면
- 구성: 페르소나 이름·경과 시간, 오디오 파형, [음소거] [종료] 버튼. **그 외 아무것도 없음** (읽을 것을 주면 대화가 죽는다).
- 5분 도달 1분 전부터 AI가 랩업 시작. 하드컷 없음 — 랩업 발화가 끝나면 AI가 인사 후 종료.
- 네트워크 끊김: 15초 내 재연결 시도 → 실패 시 통화 종료 처리 + "연결이 끊겼어요. 여기까지 일기로 만들어둘게요."

### S3. 통화 후 요약 카드 (⭐ 유일한 디자인 투자처)
위에서 아래로:
1. 날짜 + 감정 태그 칩 (체크인에서 추출, 1개)
2. **오늘의 일기** — 사용자 말투 보존 산문 3–6문단. 사용자가 말한 내용만 재구성(대필 금지). 1인칭.
3. **관찰 한 문장 (L1 미러링)** — 구분된 블록. 형식 강제: 관찰 + 직접 인용 + (당신의 말). 성격 어휘 후처리 필터 통과 필수.
4. 접힌 섹션: 전체 대화 전사 (타임스탬프, 원본 오디오 재생 버튼)
5. 하단: [삭제] — 확인 다이얼로그: "이 통화의 녹음·일기·여기서 나온 관찰이 모두 지워져요." 삭제 시 파생 관측도 제거(4-3 정책).

### S4. 홈
- 상단: 다음 통화 예고 배너 ("오늘 밤 10:30, 보라가 전화할게요") / 주간 요약 카드(발행 주)
- 본문: 일기 카드 리스트(요약 2줄 미리보기). 비어 있을 때: "첫 통화를 받으면 여기에 일기가 쌓여요."
- 금지: 스트릭 UI, "N일 연속", "3일째 안 하셨어요" 류 카피 전면 금지 (카피 가이드라인).

### S5. 설정
- 통화 시간: 요일별 시각 (기본 매일 22:30, 요일 끄기 가능 — 단 무료는 주 5회 상한과 독립)
- 시험기간 모드: 기간 선택 → 주 2회로 자동 완화 + 종료일에 원복. 일시정지(방학 모드): 최대 8주.
- 페르소나: 3종 카드 + 샘플 재생, 변경은 다음 통화부터. "페르소나를 바꿔도 기억은 그대로예요" 문구.
- 데이터: 전체 내보내기(JSON+오디오 zip, 이메일 링크), 원본 오디오 보관 기간(기본: 사용자 삭제 전까지 / 옵션: 30일 후 자동 삭제 — 선택 시 "지난 대화의 재분석이 불가해져요" 고지), 계정 삭제(전체 파기).

## 5. 시스템 동작 명세

### 5-1. 통화 파이프라인 (실시간)

```
스케줄러(서버, 유저 타임존) → APNs VoIP push → 앱 깨움 → CallKit 리포트
→ 수락 시 LiveKit 룸 연결 → Voice Agent 세션 시작
   [파이프라인] Deepgram 스트리밍 STT → LLM(경량, 페르소나 톤 프롬프트 + 7일 요약 + 오늘의 질문 플랜) → TTS 스트리밍
   [녹음] LiveKit Egress → 오브젝트 스토리지 (유저/AI 트랙 분리)
→ 종료 조건: 유저 종료 버튼 / 랩업 완료 / 연결 유실 15초
→ ⚠️ 원본 오디오 저장 성공 확인 후에만 세션 '완료' 처리 — 실패 시 재업로드 큐, 그래도 실패면 통화를 '기록 실패'로 표시하고 사과 카피 (데이터 유실 은폐 금지)
```

- 지연 목표: 유저 발화 종료 → AI 발화 시작 1.5초 이내. barge-in(끼어들기) 허용 — 유저가 말을 시작하면 TTS 즉시 중단.
- 침묵 처리: 8초 침묵 → "천천히 생각해도 돼요" 류 브릿지 1회 → 다시 12초 침묵 → 다음 질문 or 랩업.

### 5-2. 비동기 파이프라인 (통화 종료 후, 목표 30초)

```
전사 확정(타임스탬프 정렬) → LLM 잡 3개 순차:
 ① 일기 생성 (말투 보존, 대필 금지 프롬프트)
 ② 감정 태그 + L1 미러링 1문장 (직접 인용 필수, 성격어휘 필터 후처리)
 ③ 관측 후보 추출 (JSON: likes/dislikes/wants/strengths/blind_spots/values/concerns/narrative + evidence)
→ Postgres 저장 (observations는 candidate 상태로) → 일기 도착 푸시
[주간 잡] 일요일 밤: 관측 통합(candidate→emerging→established 승격, 모순은 superseded)
        + 주간 요약 생성 + 다음 주 콜백 후보 1개 선정
[통화 전 잡] 최근 7일 요약 + 콜백 1개 → 시스템 프롬프트 캐시
```

### 5-3. 위기 프로토콜 (모든 페르소나 공통, 톤보다 우선)
- 트리거: 자살·자해 어휘 사전 + LLM 분류기 이중 게이트 (LLM 단독 판정 금지)
- 경미: 공감적 인정 → 대화 지속 + 통화 후 카드에 리소스 표기하지 않음(낙인 방지), 내부 플래그만
- 고위험: 스크립트 전환 — 공감 인정 + "이런 마음은 전문가와 얘기하는 게 도움이 돼요. 자살예방상담전화 109는 24시간 열려 있어요" + 통화 후 카드에도 109 고정 표기. 미러링·일기 톤 다운.
- 모든 위기 플래그는 내부 대시보드 집계 (세션 간 누적 추적은 v1.5).

### 5-4. 원가·안전장치
- 무료: 주 5회 통화 발신, 통화당 5분(연착륙). 유료(Week 10+): 매일, 7분.
- 서버 킬스위치: 유저당 일 통화 상한 1회(+재시도 1), 월 분수 하드캡(무료 120분/유료 250분 — 초과 시 발신 중단, 도달 유저는 내부 알림).
- 내부 원가 대시보드: 분당 실원가 / 유저당 월 분수(무료·유료) / 월 API 총비용(self-host 트리거) / 위기 플래그 수.

## 6. 대화 설계 명세

### 6-1. 통화 구조 (모든 페르소나 공통 골격)
1. 인사 + 감정 체크인 (~30초): "지금 기분, 한 단어로 하면?"
2. 메인 질문 1개 (로테이션): 데일리 코어(오늘 좋았던 것 하나+이유) / 강점 신호(시간 가는 줄 몰랐던 순간) / 가치 로테이션(주 1–2회) / **기억 콜백(콜백 후보 있는 날 우선)**
3. 반영 + 인정 (OARS): 조언 금지, 되돌려주기만
4. 랩업 (~1분): "오늘 얘기를 정리해보면…" + 인사

### 6-2. 페르소나 톤 가이드 (동일 상황 예시: 유저가 "팀플 때문에 짜증났어"라고 말했을 때)
- **보라 (또래 친구, 반말)**: "아 뭐야, 또 무임승차 있었어? 뭐가 제일 빡쳤는데?"
- **무주 (담담한 기록자, 존댓말)**: "팀플에서 짜증이 났군요. 어떤 장면에서 가장 그랬어요?"
- **해나 (다정한 코치, 존댓말)**: "고생했어요, 그 와중에 끝까지 자리를 지킨 거네요. 뭐가 제일 힘들었어요?"
- 공통 금지: 진단 어휘("당신은 ~한 사람"), 설교, 3문장 초과 발화, 유저 말 끊기.

### 6-3. L1 미러링 생성 규칙 (프롬프트 계약)
- 형식: `[관찰 진술]. "[원문 인용]"(오늘 당신의 말)` — 인용 없으면 출력 무효, 재생성.
- 관찰은 해석 불가: 발화 시간 배분, 목소리 톤 변화, 반복 어휘 등 관측 가능한 사실만.
- 후처리 필터: 성격·성향 어휘 사전("성실", "창의적", "~한 사람/성격/타입" 등) 매칭 시 차단 → 재생성 (대화 10회 미만 유저 전면 적용).
- 출시 첫 2주: 전 카드 수동 QA. 어색 비율 >20%면 미러링을 주간 요약으로 후퇴 (전략서 합의).
